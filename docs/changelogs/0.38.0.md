# Scipio LLM 0.38.0 Changelog

Released 2026-10-12. Built on Hollama 0.36.0.

## Web search

Models can now search the web and read pages before answering.

- **Turning it on:** click the globe button next to the image button in the prompt bar. It turns orange when on. It's set per session and saved with the session. The button only appears for models that support tools; `scipio-think` and `scipio-code` both do.
- **What you see:** each step appears in the chat as it happens: "Searching: …" while a search runs, "Read: …" with a link for each page. The model's reasoning between steps stays collapsible, and the answer cites the pages it used.
- **Limits:** up to 3 searches and 3 page reads per answer, with each page cut to about 8,000 characters. This keeps research within the models' 16K context. A researched answer takes a minute or two.
- **Follow-up questions:** earlier answers' research steps aren't sent back to the model, to save context. Their answers, with sources, still are.
- **When search is unavailable:** if SearXNG is down, the step is shown as failed and the model answers without it.

## How it works

- Searches go through [SearXNG](https://docs.searxng.org), running on the Mac mini at `127.0.0.1:8888`. Only the Scipio UI server on the mini can reach it. SearXNG sends queries to Google, Bing and other engines without identifying who asked.
- Scipio UI's server has two new endpoints, `/api/tools/search` and `/api/tools/fetch`. The page reader only reads `http` and `https` pages. It refuses local, private and WireGuard addresses, including through redirects, so a web page can't steer the model into reaching the router, Ollama or other machines on the VPN. It reads web pages and text, not PDFs or other files.
- The design is in [docs/future-implementations/web-search.md](../future-implementations/web-search.md).

## Upgrading

On the Mac mini:

```bash
brew install python
cd ~/scipio-ui && git pull
~/scipio-ui/deploy/install-searxng.sh
~/scipio-ui/deploy/update.sh
```

`install-searxng.sh` is new and needs Python 3.10 or newer, which is why Homebrew's Python is installed first. It installs SearXNG in `~/searxng` and runs it as a launch agent (`com.tlt.searxng`). Run it again later to update SearXNG; it keeps your settings. See [DEPLOY.md](../DEPLOY.md).
