# Scipio LLM 0.37.1 Changelog

Released 2026-10-11. Built on Hollama 0.36.0.

## Changes

- The sidebar header now reads "Scipio LLM" instead of "Scipio". The browser tab title is still "Scipio".
- The favicon file is renamed from `favicon.png` to `scipio-favicon.png`. The icon itself is unchanged, but browsers that cached Hollama's icon at the same address will now load the Scipio helmet.
- The app version (for example `v0.37.1`) now shows next to "Scipio LLM" at the top of the sidebar, so you can see which version is deployed.

## Fixes

- **Empty model list.** Ollama under `brew services` was listening on `localhost` only, so the browser couldn't reach it over WireGuard. The new `deploy/install-ollama.sh` runs Ollama as its own launch agent (`com.tlt.ollama`), with `OLLAMA_ORIGINS=*` and `OLLAMA_KEEP_ALIVE=-1`. It keeps Homebrew's flash attention and `q8_0` KV cache settings. See [DEPLOY.md](../DEPLOY.md).
- **Site down after reinstalling.** Running `install.sh` a second time could leave Scipio UI stopped. macOS hadn't finished removing the old launch agent when the script started the new one, so starting it failed with "Input/output error". Both install scripts now wait for the old agent to be removed, then check that the server responds. If it doesn't, they print the last lines of its log.

## Security

- Ollama and Scipio UI now listen only on the mini's WireGuard address (`10.20.0.9`) instead of every network interface, so only WireGuard clients can reach them. The install scripts check that the address belongs to the mini before installing. Override it with `BIND_ADDRESS=...` if the WireGuard address changes.
- On the mini, Ollama commands now need the address: `OLLAMA_HOST=10.20.0.9 ollama list`.

## Upgrading

On the Mac mini, run:

```bash
cd ~/scipio-ui && git pull
~/scipio-ui/deploy/install-ollama.sh
~/scipio-ui/deploy/install.sh
```

Both launch agents changed in this release, so run both install scripts rather than `update.sh`. `install-ollama.sh` stops `brew services` for Ollama and replaces it.
