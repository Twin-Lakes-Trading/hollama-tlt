# Scipio LLM 0.37.1 Changelog

Released 2026-10-11. Built on Hollama 0.36.0.

## Changes

- The sidebar header now reads "Scipio LLM" instead of "Scipio". The browser tab title is still "Scipio".
- The favicon file is renamed from `favicon.png` to `scipio-favicon.png`. The icon itself is unchanged, but browsers that cached Hollama's icon at the same address will now load the Scipio helmet.
- The app version (for example `v0.37.1`) now shows next to "Scipio LLM" at the top of the sidebar, so you can see which version is deployed.

## Fixes

- **Empty model list.** Ollama under `brew services` was listening on `localhost` only, so the browser couldn't reach it over WireGuard. The new `deploy/install-ollama.sh` runs Ollama as its own launch agent (`com.tlt.ollama`) on `0.0.0.0:11434`, with `OLLAMA_ORIGINS=*` and `OLLAMA_KEEP_ALIVE=-1`. It keeps Homebrew's flash attention and `q8_0` KV cache settings. See [DEPLOY.md](../DEPLOY.md).

## Upgrading

On the Mac mini, run:

```bash
~/scipio-ui/deploy/update.sh
~/scipio-ui/deploy/install-ollama.sh
```

`install-ollama.sh` only needs to run once. It stops `brew services` for Ollama and replaces it.
